# Jenson_USA-Sales-SQL-Project 

## Project Overview
This project analyzes retail sales data using SQL to generate business insights related to:
- Product performance
- Customer behavior
- Staff productivity
- Revenue analysis

## SQL Skills Used
- JOINs
- CTEs
- Window Functions
- Subqueries
- Aggregations
- CASE Statements

## Key Insights
- Identified top-selling products
- Found inactive products
- Analyzed staff sales performance
- Calculated median product pricing

## Tools Used
- MySQL
- SQL
- GitHub
